1. PROJECT OVERVIEW
- Name: PortfolioIQ (README header "Portfolio Insights AI"). Objective: evidence-based portfolio intelligence — real market
  data, quantitative risk, news-event intelligence, and grounded AI explanations; BUY/HOLD/AVOID from a deterministic engine,
  never LLM-computed numbers (VERIFIED, README.md + PROJECT_DETAILS.txt).
- Users: DIY Indian-market investors (NSE symbols, Rs., NIFTY 50 `^NSEI` benchmark) + academic DB project (INFERRED from seed
  universe of 38 NSE stocks, docs, PDF course context).
- Problem: retail trackers show value/allocation but not WHY risk exists, how news maps to one's holdings, or whether a stock
  fits one's portfolio (VERIFIED, PROJECT_DETAILS.txt Section 1).
- Core features/status (all VERIFIED in code): multi-portfolio CRUD + holdings + append-only transaction ledger + watchlist;
  Yahoo Finance primary / Alpha Vantage fallback sync (45-min scheduler); risk engine (vol, Sharpe/Sortino/Calmar, VaR/CVaR,
  HHI, Euler contributions, Beta/Alpha vs NIFTY); GDELT/Marketaux news -> entities -> events -> exposure -> alerts; RAG +
  local LLM AI layer; AI Deep Analysis with decision engine; JWT auth, RBAC, audit log, rate limiting, Docker Compose.
- PDF requirements: see section 16.
